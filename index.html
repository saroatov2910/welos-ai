Five promises

Under 15 ms Live

Local rules, no network calls in the decision path.

Data stays inside Live

Network policy blocks all outbound traffic. Local audit log, masked card numbers, CVV never stored.

An AI reviewer reads each rule change and flags critical issues. Built, not yet a pipeline gate.

Control from phone Blocking live

Risky cards are blocked automatically; the security manager can block or release a card through the API. Phone alerts are planned.

How a transaction is decided

Every request passes the same steps, all inside the customer network.

01

API key

Only registered stores can ask.

02

Validation

Luhn check, CVV, expiry, amount, timezone.

03

Blocklist

Blocked cards are rejected at once, matched by an HMAC, never by the number.

04

Risk score

Rules add points from 0 to 100.

05

Decision

Accept, review or reject. A score of 90+ blocks the card for 24 hours.

06

Audit

Written to a local, append-only log.
